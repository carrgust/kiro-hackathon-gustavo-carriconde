# AutoCoder Integration Specification

## Overview

Integrate an autonomous coding agent that receives the PRD generated by the DNA pipeline, decomposes it into implementable features, and builds a single-page HTML mockup in real time — displayed live in an iframe within the AutoCoder tab.

## Architecture

```
┌─────────────────────────────────────────────────────┐
│                   CURATOS DNA UI                     │
│                                                      │
│  PRD Section ──────────────────► AutoCoder Section   │
│  (generate-prd)    PRD JSON      ┌───────────────┐  │
│                        │         │ Progress Panel │  │
│                        ▼         │ Feature List   │  │
│               POST /api/autocoder│ Event Log      │  │
│                    /start        │                │  │
│                        │         │ ┌───────────┐ │  │
│                        ▼         │ │  IFRAME   │ │  │
│              ┌─────────────────┐ │ │ (preview) │ │  │
│              │ AutoCoder Engine│ │ │           │ │  │
│              │                 │ │ └───────────┘ │  │
│              │ Phase 1: Init   │ └───────────────┘  │
│              │  PRD → Features │         ▲          │
│              │                 │         │          │
│              │ Phase 2: Code   │    WebSocket       │
│              │  Feature loop   │    events           │
│              │  → index.html   │─────────┘          │
│              └─────────────────┘                     │
└─────────────────────────────────────────────────────┘
```

## PRD JSON Schema

The autocoder expects a structured PRD. The DNA pipeline's generate-prd endpoint must output this format:

```typescript
// src/lib/autocoder/types.ts

import { z } from "zod";

export const TargetUserSchema = z.object({
  id: z.string().regex(/^U-\d{3}$/),
  persona: z.string(),
  age_range: z.string().default(""),
  description: z.string(),
  pain_points: z.array(z.string()).default([]),
  primary_need: z.string().default(""),
});

export const UserStorySchema = z.object({
  id: z.string().regex(/^US-\d{3}$/),
  persona_id: z.string(),
  story: z.string(),
  acceptance_criteria: z.array(z.string()).default([]),
});

export const FunctionalRequirementSchema = z.object({
  id: z.string().regex(/^FR-\d{3}$/),
  name: z.string(),
  story_ids: z.array(z.string()).default([]),
  priority: z.number().int().min(1).default(1),
  description: z.string(),
});

export const NonFunctionalRequirementSchema = z.object({
  id: z.string().regex(/^NFR-\d{3}$/),
  name: z.string(),
  category: z.string(),
  applies_to: z.union([z.array(z.string()), z.literal("global")]).default("global"),
  description: z.string(),
  target: z.string().default(""),
});

export const ConstraintsSchema = z.object({
  language: z.string().default(""),
  framework: z.string().default(""),
  dependencies: z.string().default(""),
  output_format: z.string().default(""),
});

export const PRDSchema = z.object({
  executive_summary: z.string(),
  target_users: z.array(TargetUserSchema).default([]),
  user_stories: z.array(UserStorySchema).default([]),
  functional_requirements: z.array(FunctionalRequirementSchema).default([]),
  non_functional_requirements: z.array(NonFunctionalRequirementSchema).default([]),
  constraints: ConstraintsSchema.default({}),
});

export type PRD = z.infer<typeof PRDSchema>;
export type TargetUser = z.infer<typeof TargetUserSchema>;
export type UserStory = z.infer<typeof UserStorySchema>;
export type FunctionalRequirement = z.infer<typeof FunctionalRequirementSchema>;
export type NonFunctionalRequirement = z.infer<typeof NonFunctionalRequirementSchema>;
```

## Feature Model

Features are the unit of work. Each maps to one functional requirement with full traceability:

```typescript
// src/lib/autocoder/types.ts (continued)

export const FeatureStatusEnum = z.enum(["pending", "in_progress", "done", "skipped"]);

export const FeatureSchema = z.object({
  id: z.string(),
  name: z.string(),
  description: z.string(),
  status: FeatureStatusEnum.default("pending"),
  priority: z.number().int().min(1).default(1),
  category: z.string().optional(),
  fr_id: z.string().optional(),
  story_ids: z.array(z.string()).default([]),
  nfr_ids: z.array(z.string()).default([]),
  acceptance_criteria: z.array(z.string()).default([]),
  attempts: z.number().int().default(0),
  created_at: z.string().default(() => new Date().toISOString()),
  completed_at: z.string().optional(),
});

export type Feature = z.infer<typeof FeatureSchema>;
export type FeatureStatus = z.infer<typeof FeatureStatusEnum>;
```

## Implementation

### Step 1: AutoCoder Engine Service

Location: `src/lib/autocoder/engine.ts`

The engine orchestrates the two-phase pipeline. It uses the existing OpenRouter client for LLM calls.

```typescript
import { callModel } from "@/lib/config/models";
import type { PRD, Feature } from "./types";

export interface AutoCoderEvent {
  type:
    | "pipeline_started"
    | "phase_started"
    | "feature_started"
    | "feature_completed"
    | "feature_skipped"
    | "feature_error"
    | "progress"
    | "preview_updated"
    | "pipeline_completed"
    | "error";
  timestamp: string;
  [key: string]: unknown;
}

export async function* runAutoCoderPipeline(
  prd: PRD,
  projectId: string,
  apiKey: string,
): AsyncGenerator<AutoCoderEvent> {
  yield { type: "pipeline_started", timestamp: now(), projectId };

  // Phase 1: Decompose PRD into features
  yield { type: "phase_started", timestamp: now(), phase: "initializer" };
  const features = await decomposePRDToFeatures(prd, apiKey);
  yield { type: "phase_started", timestamp: now(), phase: "coder", totalFeatures: features.length };

  // Phase 2: Implement each feature
  let html = "";
  let completed = 0;

  for (const feature of features) {
    feature.status = "in_progress";
    feature.attempts += 1;
    yield { type: "feature_started", timestamp: now(), feature };

    try {
      html = await implementFeature(feature, html, prd, apiKey);
      feature.status = "done";
      feature.completed_at = now();
      completed += 1;
      yield { type: "feature_completed", timestamp: now(), feature, completed, total: features.length };
      yield { type: "preview_updated", timestamp: now(), html };
    } catch (error) {
      if (feature.attempts >= 3) {
        feature.status = "skipped";
        yield { type: "feature_skipped", timestamp: now(), feature };
      } else {
        yield { type: "feature_error", timestamp: now(), feature, error: String(error) };
      }
    }

    yield { type: "progress", timestamp: now(), completed, total: features.length };
  }

  yield { type: "pipeline_completed", timestamp: now(), completed, total: features.length };
}

function now(): string {
  return new Date().toISOString();
}
```

### Step 2: PRD-to-Features Decomposition

Location: `src/lib/autocoder/decomposer.ts`

Uses the LLM to break the PRD into ordered features with traceability:

```typescript
import { callModel } from "@/lib/config/models";
import type { PRD, Feature } from "./types";

const DECOMPOSER_SYSTEM_PROMPT = `You are a software architect. Decompose this PRD into implementable UI features for a single-page HTML mockup.

RULES:
1. Feature 1: HTML scaffold + design system (fonts, CSS variables, reset)
2. Feature 2: Navigation/header
3. Features 3-N: Visual sections top-to-bottom (hero, features, content, forms, footer)
4. Last feature: Polish, animations, scroll effects
5. Total: 5-15 features
6. Each feature must reference its FR-xxx, US-xxx IDs, and acceptance criteria

Return ONLY a JSON array of features. No other text.`;

export async function decomposePRDToFeatures(prd: PRD, apiKey: string): Promise<Feature[]> {
  const prdText = formatPRDForPrompt(prd);

  const response = await callModel({
    apiKey,
    messages: [
      { role: "system", content: DECOMPOSER_SYSTEM_PROMPT },
      { role: "user", content: `Decompose this PRD into features:\n\n${prdText}` },
    ],
    responseFormat: "json",
  });

  const features: Feature[] = JSON.parse(response);
  return features.sort((a, b) => a.priority - b.priority);
}

function formatPRDForPrompt(prd: PRD): string {
  const sections: string[] = [];
  sections.push(`## Executive Summary\n${prd.executive_summary}`);

  if (prd.target_users.length > 0) {
    sections.push("## Target Users");
    for (const u of prd.target_users) {
      sections.push(`- [${u.id}] ${u.persona}: ${u.description}`);
    }
  }

  if (prd.user_stories.length > 0) {
    sections.push("## User Stories");
    for (const s of prd.user_stories) {
      sections.push(`- [${s.id}] (persona: ${s.persona_id}) ${s.story}`);
      for (const ac of s.acceptance_criteria) {
        sections.push(`  - AC: ${ac}`);
      }
    }
  }

  if (prd.functional_requirements.length > 0) {
    sections.push("## Functional Requirements");
    for (const fr of prd.functional_requirements) {
      const stories = fr.story_ids.length > 0 ? fr.story_ids.join(", ") : "none";
      sections.push(`- [${fr.id}] ${fr.name} (priority: ${fr.priority}, stories: ${stories})`);
      sections.push(`  ${fr.description}`);
    }
  }

  if (prd.non_functional_requirements.length > 0) {
    sections.push("## Non-Functional Requirements");
    for (const nfr of prd.non_functional_requirements) {
      const applies = Array.isArray(nfr.applies_to) ? nfr.applies_to.join(", ") : nfr.applies_to;
      sections.push(`- [${nfr.id}] ${nfr.name} (${nfr.category}, applies to: ${applies})`);
      sections.push(`  ${nfr.description}${nfr.target ? ` Target: ${nfr.target}` : ""}`);
    }
  }

  return sections.join("\n\n");
}
```

### Step 3: Feature-to-HTML Implementation

Location: `src/lib/autocoder/implementer.ts`

Each feature is implemented by asking the LLM to add a section to the growing index.html:

```typescript
import { callModel } from "@/lib/config/models";
import type { Feature, PRD } from "./types";

const CODER_SYSTEM_PROMPT = `You are a world-class UI/UX designer. You build stunning single-page HTML mockups.

OUTPUT: Return ONLY the complete updated index.html content. No markdown, no explanation — just HTML.

RULES:
- Single index.html with ALL CSS in <style> and JS in <script>
- Google Fonts via CDN only — no system fonts
- Fully responsive (320px to 2560px)
- CSS custom properties for theming
- Vanilla JS only
- Distinctive typography, bold colors, motion/animations
- Never use plain white backgrounds

You will receive the current HTML and a section to add. Return the FULL updated HTML.`;

export async function implementFeature(
  feature: Feature,
  currentHtml: string,
  prd: PRD,
  apiKey: string,
): Promise<string> {
  const userMessage = currentHtml
    ? `Current index.html:\n\`\`\`html\n${currentHtml}\n\`\`\`\n\nAdd this section:\nName: ${feature.name}\nDetails: ${feature.description}\n\nReturn the COMPLETE updated HTML.`
    : `Create the initial index.html scaffold for: ${prd.executive_summary}\n\nSection: ${feature.name}\nDetails: ${feature.description}\n\nReturn the COMPLETE HTML file.`;

  const response = await callModel({
    apiKey,
    messages: [
      { role: "system", content: CODER_SYSTEM_PROMPT },
      { role: "user", content: userMessage },
    ],
  });

  // Strip markdown code fences if present
  let html = response.trim();
  if (html.startsWith("```")) {
    html = html.replace(/^```(?:html)?\n?/, "").replace(/\n?```$/, "");
  }

  return html;
}
```

### Step 4: API Routes

#### Start Pipeline

Location: `src/app/api/autocoder/start/route.ts`

```typescript
import { NextRequest, NextResponse } from "next/server";
import { PRDSchema } from "@/lib/autocoder/types";
import { runAutoCoderPipeline } from "@/lib/autocoder/engine";

// Store active sessions in memory (replace with Redis in production)
const sessions = new Map<string, { html: string; events: unknown[]; status: string }>();

export async function POST(req: NextRequest) {
  const body = await req.json();
  const { prd, apiKey } = body;

  // Validate PRD
  const parsed = PRDSchema.safeParse(prd);
  if (!parsed.success) {
    return NextResponse.json({ error: "Invalid PRD", details: parsed.error.issues }, { status: 400 });
  }

  const sessionId = crypto.randomUUID();
  sessions.set(sessionId, { html: "", events: [], status: "running" });

  // Run pipeline in background (non-blocking)
  (async () => {
    try {
      for await (const event of runAutoCoderPipeline(parsed.data, sessionId, apiKey)) {
        const session = sessions.get(sessionId);
        if (!session) break;

        session.events.push(event);

        if (event.type === "preview_updated") {
          session.html = event.html as string;
        }
        if (event.type === "pipeline_completed" || event.type === "error") {
          session.status = "completed";
        }
      }
    } catch (error) {
      const session = sessions.get(sessionId);
      if (session) {
        session.status = "error";
        session.events.push({ type: "error", timestamp: new Date().toISOString(), message: String(error) });
      }
    }
  })();

  return NextResponse.json({ sessionId });
}
```

#### Poll Status & Events

Location: `src/app/api/autocoder/status/[id]/route.ts`

```typescript
import { NextRequest, NextResponse } from "next/server";

export async function GET(req: NextRequest, { params }: { params: { id: string } }) {
  const session = sessions.get(params.id);
  if (!session) {
    return NextResponse.json({ error: "Session not found" }, { status: 404 });
  }

  // Return events since last poll (use query param ?after=N)
  const after = parseInt(req.nextUrl.searchParams.get("after") || "0");
  const newEvents = session.events.slice(after);

  return NextResponse.json({
    status: session.status,
    totalEvents: session.events.length,
    events: newEvents,
  });
}
```

export async function GET(req: NextRequest, { params }: { params: { id: string } }) {
  const session = sessions.get(params.id);
  if (!session || !session.html) {
    return new NextResponse("<html><body><p>Building...</p></body></html>", {

### Step 5: AutoCoder Section UI

Location: `src/components/sections/AutoCoderSection.tsx`

Split-pane layout: left = progress/features/log, right = live iframe preview.

```typescript
"use client";

import { useState, useEffect, useCallback } from "react";
import { motion } from "framer-motion";

interface AutoCoderSectionProps {
  prd: PRD | null;
  apiKey: string;
}

export function AutoCoderSection({ prd, apiKey }: AutoCoderSectionProps) {
  const [sessionId, setSessionId] = useState<string | null>(null);
  const [events, setEvents] = useState<AutoCoderEvent[]>([]);
  const [status, setStatus] = useState<"idle" | "running" | "completed" | "error">("idle");
  const [previewKey, setPreviewKey] = useState(0);
  const [progress, setProgress] = useState({ completed: 0, total: 0 });

  const startPipeline = async () => {
    if (!prd) return;
    setStatus("running");

    const res = await fetch("/api/autocoder/start", {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ prd, apiKey }),
    });

    const { sessionId } = await res.json();
    setSessionId(sessionId);
  };

  // Poll for events
  useEffect(() => {
    if (!sessionId || status !== "running") return;

    const interval = setInterval(async () => {
      const res = await fetch(`/api/autocoder/status/${sessionId}?after=${events.length}`);
      const data = await res.json();

      if (data.events.length > 0) {
        setEvents(prev => [...prev, ...data.events]);

        for (const event of data.events) {
          if (event.type === "preview_updated") setPreviewKey(k => k + 1);
          if (event.type === "progress") setProgress({ completed: event.completed, total: event.total });
          if (event.type === "pipeline_completed") setStatus("completed");
          if (event.type === "error") setStatus("error");
        }
      }

      if (data.status !== "running") setStatus(data.status);
    }, 2000);

    return () => clearInterval(interval);
  }, [sessionId, status, events.length]);

  return (
    <div className="grid grid-cols-2 gap-6 h-[80vh]">
      {/* Left: Controls + Feature Progress */}
      <div className="flex flex-col gap-4 overflow-auto">
        <button onClick={startPipeline} disabled={!prd || status === "running"}>
          {status === "running" ? "Building..." : "Generate App"}
        </button>

        {/* Progress bar */}
        {progress.total > 0 && (
          <div className="w-full bg-gray-800 rounded-full h-3">
            <div
              className="bg-emerald-500 h-3 rounded-full transition-all duration-500"
              style={{ width: `${(progress.completed / progress.total) * 100}%` }}
            />
          </div>
        )}

        {/* Feature list */}
        {events
          .filter(e => ["feature_started", "feature_completed", "feature_skipped"].includes(e.type))
          .map((e, i) => (
            <div key={i} className="flex items-center gap-2">
              <span>{e.type === "feature_completed" ? "✓" : e.type === "feature_skipped" ? "⏭" : "⚙"}</span>
              <span>{(e.feature as Feature)?.name}</span>
            </div>
          ))}

        {/* Event log */}
        <div className="font-mono text-xs text-gray-400 overflow-auto max-h-[300px]">
          {events.map((e, i) => (
            <div key={i}>[{e.type}] {JSON.stringify(e).slice(0, 120)}</div>
          ))}
        </div>
      </div>

      {/* Right: Live Preview */}
      <div className="border border-gray-700 rounded-lg overflow-hidden">
        {sessionId ? (
          <iframe
            key={previewKey}
            src={`/api/autocoder/preview/${sessionId}`}
            className="w-full h-full border-0"
            title="Live Preview"
          />
        ) : (
          <div className="flex items-center justify-center h-full text-gray-500">
            Click "Generate App" to start building
          </div>
        )}
      </div>
    </div>
  );
}
```

## Integration Points

### Trigger: PRD Section → AutoCoder Section

The AutoCoder tab receives the PRD object from the DNA pipeline state. The PRD is already in memory after the generate-prd step:

```typescript
// In src/app/page.tsx, pass prdData to AutoCoderSection
<AutoCoderSection prd={prdData} apiKey={apiKey} />
```

### Data Flow

1. User clicks "Generate App" in AutoCoder tab
2. `POST /api/autocoder/start` with PRD JSON + API key
3. Server starts pipeline, returns sessionId
4. Client polls `GET /api/autocoder/status/{id}?after=N` every 2 seconds
5. On `preview_updated` event, iframe reloads from `GET /api/autocoder/preview/{id}`
6. On `pipeline_completed`, polling stops

### Session State

The autocoder stores active session state in a module-level Map. For the hackathon, this is sufficient. In production, use Redis or database-backed sessions.

```typescript

## Success Criteria

- [ ] PRD JSON is validated with Zod before pipeline starts
- [ ] PRD decomposes into 5-15 traceable features via LLM
- [ ] Each feature includes fr_id, story_ids, nfr_ids, acceptance_criteria
- [ ] Features are implemented sequentially, each adding to index.html
- [ ] index.html is valid and renderable after each feature
- [ ] Live iframe preview updates after each feature completes
- [ ] Progress bar shows completed/total features
- [ ] Feature list shows status (pending/in_progress/done/skipped)
- [ ] Event log streams real-time pipeline activity
- [ ] Failed features retry up to 3 times before skipping
- [ ] Pipeline completes even if some features are skipped
- [ ] "Generate App" button is disabled while pipeline runs
- [ ] Works with free-tier OpenRouter models (GLM 4.7 Flash, DeepSeek)

## Error Handling

- **Invalid PRD**: Return 400 with Zod validation errors
- **LLM failure**: Retry feature up to 3 times, then skip
- **Session not found**: Return 404 on status/preview polling
- **Pipeline crash**: Set session status to "error", emit error event
- **Malformed HTML response**: Strip markdown fences, attempt to render anyway
